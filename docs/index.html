qmpo

Browsers block file:// links for security. qmpo provides a directory:// URI scheme that safely opens directories in your file manager.

How it works

🌐
Click a file:// link on a web page
→
🔄
Extension converts to directory://
→
📂
File manager opens the folder

Install

Platform Method
Windows Download .zip → run qmpo-lau.exe
macOS Download .zip → run qmpo-lau register
Arch Linux makepkg -si from aur/
NixOS programs.qmpo.enable = true; via flake
Other cargo build --release from source
