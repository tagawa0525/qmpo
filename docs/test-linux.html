How It Works

qmpo consists of three components:

  1. qmpo - The URI handler that receives directory:// URIs and opens them in your file manager
  2. qmpo-lau - A registration tool that sets up qmpo as the system's directory:// protocol handler
  3. Chrome Extension - Converts file:// links to directory:// on web pages

Linux Implementation

  • Creates a desktop entry at ~/.local/share/applications/qmpo.desktop
  • Installs the binary to ~/.local/bin/qmpo
  • Registers as MIME handler using xdg-mime
  • Opens directories using xdg-open

Chrome Extension

  • Content script runs on every page and detects file:// links
  • Converts file:// URLs to directory:// URLs when clicked
  • Triggers the system protocol handler via a hidden iframe
  • Adds a folder icon (📂) to converted links as a visual indicator
Setup Required:

Ensure qmpo is installed and registered: qmpo-lau status

Expected Behavior

  • directory:// - Opens in system file manager (Nautilus, Dolphin, etc.)
  • file:// - Handled by Chrome extension (if installed)
  • Clicking a file link should open the parent folder with the file selected
  • Clicking a directory link should open that directory
