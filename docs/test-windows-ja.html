qmpo テストページ - Windows

Linux macOS Windows English

仕組み

qmpoは3つのコンポーネントで構成されています：

  1. qmpo - directory:// URIを受け取り、ファイルマネージャーで開くURIハンドラー
  2. qmpo-lau - qmpoをシステムの directory:// プロトコルハンドラーとして登録するツール
  3. Chrome拡張機能 - Webページ上の file:// リンクを directory:// に変換

Windowsでの実装

  • Windowsレジストリにプロトコルハンドラーを登録（HKCU\Software\Classes\directory）
  • バイナリを %LOCALAPPDATA%\qmpo\qmpo.exe にインストール
  • explorer.exe でディレクトリを開く

Chrome拡張機能

  • Content scriptが各ページで file:// リンクを検出
  • クリック時に file:// URLを directory:// URLに変換
  • 隠しiframeでシステムのプロトコルハンドラーをトリガー
  • 変換されたリンクにフォルダアイコン（📂）を表示
セットアップが必要です：

qmpoがインストール・登録されていることを確認してください: qmpo-lau status

テストリンク (directory://)

これらの directory:// リンクをクリックしてエクスプローラーで開きます。

directory://C:/Users (ユーザーディレクトリ) directory://C:/Windows/System32/drivers/etc/hosts (ファイル - 選択状態で開く) directory://C:/Program Files (Program Files) directory://C:/Windows (Windowsディレクトリ) directory://C:/Temp (一時ディレクトリ)

テストリンク (file://)

これらの file:// リンクをクリックしてChrome拡張機能の動作をテストします。

file://C:/Users (ユーザーディレクトリ) file://C:/Windows/System32/drivers/etc/hosts (ファイル) file://C:/Program Files (Program Files) file://C:/Windows (Windowsディレクトリ) file://C:/Temp (一時ディレクトリ)

期待される動作

  • directory:// - エクスプローラーで開く
  • file:// - Chrome拡張機能（インストール済みの場合）で処理
  • ファイルリンクをクリックすると、親フォルダが開きファイルが選択される
  • ディレクトリリンクをクリックすると、そのディレクトリが開く
