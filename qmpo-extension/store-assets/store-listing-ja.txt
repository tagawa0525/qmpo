ブラウザはセキュリティ上 file:// リンクをブロックします。でも、必要な場面がある。

qmpo は Web ページ上の file:// リンクを directory:// スキームに変換し、フォルダをファイルマネージャーで直接開きます。社内 Wiki、ドキュメントサイト、共有フォルダへのリンクに最適です。

仕組み：
1. ページ上の file:// リンクを自動検出
2. クリック時に directory:// URI に変換
3. ファイルマネージャーでフォルダが開く（ファイルは選択状態）

機能：
- file:// → directory:// の自動変換
- 変換済みリンクにフォルダアイコン（📂）を表示
- ドメインの許可リスト／ブロックリストに対応
- Windows Explorer、macOS Finder、Linux ファイルマネージャーに対応
- ポップアップからサイトごとに ON/OFF 切り替え

必要条件：
qmpo URI ハンドラーのインストールが必要です。
ダウンロード: https://github.com/tagawa0525/qmpo

プライバシー：
データの収集・送信は一切行いません。すべての処理はブラウザ内で完結します。

---
English: qmpo converts file:// links to the directory:// scheme, opening folders in your file manager. Requires the qmpo URI handler (https://github.com/tagawa0525/qmpo).
